## How to use

1. Write the date and the judge's name (or "unnamed judge" and the panel).
2. Paste the comment word for word, with the language it was given in.
3. Within a day, write the action: fixed (commit or file), added to `docs/CHECKLIST.md` as a task, or "not acting, because ..." with the reason.
4. If the feedback changes a number or claim in the report or deck, update `docs/report/results.md` first and re-run the number check.
